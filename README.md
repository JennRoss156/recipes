Issues I faced and how I resolved each one:

1. Images not appearing when opening in browser. Steps taken to resolve the issue: I reviewed the steps for adding an image to your web page using The Odin Project Lesson- Links & Images. I checked out Chrome's developer tools and viewed the console section to read any errors while the page was loaded in the browser. There is where I noticed the path to each image was incorrect. I edited each image to point directly to that image. In VSCode, I
right-clicked the image and selected> copy path. This gave me the correct file path. Issue has been resolved.
